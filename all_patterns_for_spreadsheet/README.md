# BBL 成長期別経験値のExcel出力

野球系Webゲーム「[Baseball Life(以下、BBL)](https://baseball-life.games/)」の練習時の経験値を計算するPythonプログラムです。
BBLでは、選手の登録時に決まる成長型と年齢によって成長期が決まり、成長期ごとに練習で得られる経験値の範囲が異なります。このプログラムは、成長期ごとの経験値の範囲をCSVから読み込み、補正条件別の出現値と期待値をExcelに出力します。

小AP・YUR・集中／イマイチ・筋肉養成ギプスの補正条件の組み合わせをシートに分け、AP、メンタリスト、各鍛錬、自主トレ参加の結果を列ごとに出力します。

この文書は、BBLの2026年9月29日現在の実装(Ver. 0.4.3.6)を元に説明しています。ゲームの最新仕様との一致を保証するものではありません。

本ツールは個人が作成した非公式ツールで、BBLの運営とは関係ありません。

## 必要な環境

- Python 3.14以上
- openpyxl 3.1.5以上
- [uv](https://docs.astral.sh/uv/)(以下の環境構築手順で使用)

依存関係は [pyproject.toml](./pyproject.toml)、解決済みのバージョンは [uv.lock](./uv.lock) で管理しています。

## 環境構築と実行

最初に、このリポジトリをローカルにcloneします。

```sh
git clone https://github.com/JiroShirato/bbl_growth_type_output.git
cd bbl_growth_type_output/all_patterns_for_spreadsheet
```

このプロジェクトのフォルダーをターミナルで開き、実行します。

```sh
uv sync
uv run python main.py
```

初期設定では成長期毎に設定されている3種類(非AP小練習/非AP大練習/大練習マイナス)の無補正の経験値の出現値を記載した [import.csv](./import.csv) を読み込み、作業フォルダーに `output.xlsx` を保存します。

入出力を指定する場合:

```sh
uv run python main.py -i import.csv -o result.xlsx
```

| オプション | 意味 | 省略時 |
|---|---|---|
| `-i`, `--input` | 入力CSVのパス | `import.csv` |
| `-o`, `--output` | 出力Excelのパス | `output.xlsx` |
| `-h`, `--help` | ヘルプを表示 | — |

相対パスは、プログラムの配置場所ではなく実行時の作業フォルダーを基準に解釈されます。空白を含むパスは引用符で囲んでください。

出力先のフォルダーは事前に作成してください。同名の出力ファイルは確認なしで上書きされます。保存先のExcelファイルを開いている場合は、閉じてから実行してください。

既存の仮想環境で直接実行することもできます。

### Windowsでの実行例
```powershell
.\.venv\Scripts\python.exe main.py -i import.csv -o result.xlsx
```

### Linux/macOSでの実行例
```sh
./.venv/bin/python main.py -i import.csv -o result.xlsx
```

## 入力CSV

UTF-8(BOMなし)、ヘッダーなし、1行7列で用意します。1行が1つの成長期パターンです。空行を含めず、成長期名は重複しない名前にしてください。

| 列 | 内容 | 例 |
|---|---|---|
| 1 | 成長期名 | 通常期1 |
| 2 | 非AP小練習の最小値 | 4 |
| 3 | 非AP小練習の最大値 | 6 |
| 4 | 非AP大練習の最小値 | 7 |
| 5 | 非AP大練習の最大値 | 9 |
| 6 | 大練習マイナスの最大値(0に近い側) | -1 |
| 7 | 大練習マイナスの最小値(0から遠い側) | -2 |

```csv
停滞期00,0,0,0,0,0,0
停滞期01,,,0,1,0,0
通常期1,4,6,7,9,-1,-2
```

大練習マイナスだけは「最大値、最小値」の順です。減少しない場合は、最後の2列を `0,0` にします。

数値は整数で指定します。非AP小練習・非AP大練習は `最小値 <= 最大値` になるように設定してください。逆に指定した場合は、最小値と最大値を入れ替えて扱います。

非AP小練習・非AP大練習の最小値または最大値が空欄の場合、その練習の出現値は空になります。非AP小練習が空の場合、自主トレ参加も空になります。意図的にデータなしにする場合は、最小値・最大値の両方を空欄にしてください。大練習マイナスの空欄はエラーになります。

同梱の [test.csv](./test.csv) は全項目が空欄の1行で、エラー確認用です。通常の出力には使用しません。

## 出力Excel

現在の設定では48シートを生成します。同梱CSVでは各シートが17データ行と1説明行、39列になります。

### シート名

シート名は5桁のコードです。左から次の条件を表します。

| 桁 | 条件 | 値 |
|---|---|---|
| 1 | 小AP | `0`: なし、`1`: あり |
| 2 | YUR | `0`: なし、`1`: あり |
| 3 | 集中・イマイチ | `0`: なし、`1`: 集中、`2`: イマイチ |
| 4 | 筋肉養成ギプス | `0`: なし、`1`: あり |
| 5 | 出力内容 | `0`: 出現値、`1`: 期待値 |

例: `00000` はすべてのシート条件がなしの出現値、`11211` は小AP・YUR・イマイチ・ギプスありの期待値です。各シートのデータ直後の行には、A列に条件名、B列に出力内容を記載します。

### 行・列とセルの形式

- データ行はCSVの順です。成長期名はセルに出力されません。
- 列見出しは出力されません。A列から [init_values.py](./init_values.py) の `OUTPUT_COLUMN_NAME_LIST` の順に並び、各行のコメントが列の説明です。
- 出現値はカンマ区切りや `～` による範囲表記になります。
- 期待値は頻度を重みとして計算し、小数点以下2桁に丸めます。末尾のゼロを含めて常に2桁表示する形式ではありません。
- 値がない場合は文字列 `None` を出力します。
- 期待値を含め、データセルは数値や数式ではなく文字列です。Excelで集計する場合は数値への変換が必要です。

## 一覧表テンプレート

[base_spreadsheet.xlsx](./base_spreadsheet.xlsx) は、出力Excelの結果を条件を選んで表示するための一覧表のテンプレートです。「一覧表」シートだけを含み、出力Excelのシートは含みません。Pythonプログラムで出力されるExcelの全シート(「01000」シートなど48シート)を同じブックに入れて使います。

- D3～D7で小AP・YUR・集中/イマイチ・筋肉養成ギプス・出力内容を選ぶと、C40でシート名(5桁のコード)を組み立て、`INDIRECT` 関数でそのシートの値を表示します。G2とK2には、そのシートの条件名と出力内容を表示します。
- G5～G7でAP・メンタリスト嫁・鍛錬系共通能力を選ぶと、条件に合わない列が黒く塗りつぶされます(条件付き書式)。
- 10～26行目の成長期名は、同梱の [import.csv](./import.csv) の行の順に合わせて入力しています。CSVの行を追加・並べ替えた場合は、この列も合わせて修正してください。
- 28～38行目は、成長型ごとの年齢と成長期の対応表です。

Excelで保存すると、ファイルのプロパティ(最終更新者など)にExcelのユーザー名が記録されます。公開するリポジトリにコミットする前に、プロパティに個人情報が含まれていないか確認してください。

### ローカルでExcelのファイルを使う方法

次の手順で、[参考URL](#参考url)で公開しているGoogleスプレッドシートと同じように、手元のExcelで一覧表を使えます。[環境構築と実行](#環境構築と実行)の手順で、出力Excelを作成済みであることを前提とします。

1. 出力Excel(以下、`output.xlsx` とします)と [base_spreadsheet.xlsx](./base_spreadsheet.xlsx) を開きます。
2. `base_spreadsheet.xlsx` の「一覧表」シートのタブを右クリックし、「移動またはコピー」で移動先に `output.xlsx` を選び、「コピーを作成する」にチェックを入れてコピーします。
3. `output.xlsx` を別の名前で保存します。`main.py` を再実行すると `output.xlsx` は上書きされ、コピーしたシートも消えるためです。
4. コピーした「一覧表」シートの条件欄(D3～D7、G5～G7)を選ぶと、対応する結果が表示されます。

## 計算の流れ

対象となる練習について、次の順序で計算します。すべての補正をすべての列に適用するわけではありません。

1. CSVの最小値から最大値までの整数を、各頻度1で作成
2. 小APによる加算(初期設定は、+2)
3. AP倍率を適用(初期設定は、ミート1.3倍、パワー1.4倍、その他1.5倍。端数を切り捨て)
4. YURによる加算(初期設定は、+4)
5. メンタリストの対象パターンを作成(初期設定は、精神練習2倍)
6. 集中(+3、+4、+5)またはイマイチ(2で割り、切り捨てと切り上げが半々の確率)
7. 積極・慎重・精密・平衡鍛錬のパターンを作成
8. 筋肉養成ギプスを適用(初期設定は、1.2倍。端数切り上げ)
9. (出力内容の設定に応じて)期待値を計算し、出力

「初期設定」と書いた加算値と倍率は、[init_values.py](./init_values.py) で変更できます。倍率は小数点以下1桁までで指定してください。

手順7のそれぞれの鍛錬は、集中・イマイチまで適用したパターンを元に作成します。

| 鍛錬 | 対象 | 処理 |
|---|---|---|
| 積極 | 大練習(メンタリストは除く)、新球大練習(非AP小練習の値を使用) | +2、+3、+4 |
| 積極 | 大練習マイナス | -1、-2を加算(減算処理) |
| 慎重 | 大練習マイナス | 2で割り、切り捨てと切り上げが半々の確率 |
| 精密 | 小練習(AP・メンタリストを含む) | 6以上は+2、1～5は+1、0以下はそのまま |
| 平衡 | 大練習・小練習(AP・メンタリストを含む) | 1以上なら+1、+2、+3、0以下はそのまま |

積極・慎重は、その成長期に大練習マイナスがある(CSVの6列目が負の数)場合だけ補正がかかり、ない場合は補正前と同じ値を出力します。筋肉養成ギプスは大練習・小練習の列(鍛錬適用後を含む)が対象で、大練習マイナスと自主トレ参加には適用しません。

自主トレ参加は、非AP小練習の元の最小値・最大値をそれぞれ3倍した範囲の整数から作成し、上記の補正は適用しません。具体的な対象判定と鍛錬の処理は [sub_functions.py](./sub_functions.py) の `calc_growth_patterns()` と、[one_pattern_class.py](./one_pattern_class.py) を参照してください。

## エラーと終了コード

| 終了コード | 意味 |
|---|---|
| `0` | 正常終了。ヘルプ表示の場合も0 |
| `1` | 入出力や入力データなどの処理エラー |
| `2` | コマンドライン引数の指定エラー(argparse) |

入力ファイルなし、0行のCSV、空行や列数が7列未満の行、不正な整数、大練習マイナスの空範囲、UTF-8で読めない入力、不正なAP倍率の設定、保存失敗はエラー表示の対象です。列数不足と空行のエラーには、該当する行番号が表示されます。

現状、入力検証は完全ではありません。

- 同じ成長期名が複数ある場合、後の行が前のデータを上書きします。
- 8列目以降は参照しません。
- 非AP小練習・非AP大練習の最小値が最大値を超える場合は、入れ替えて扱います。

入力形式を満たすCSVで利用してください。

## 別のPythonファイルから呼び出す

同じフォルダーのPythonファイルから、次のように実行できます。

```python
from main import main

try:
    main(input_file="import.csv", output_file="result.xlsx")
except (OSError, ValueError) as exc:
    print(f"出力に失敗しました: {exc}")
```

`main()` の戻り値は `None` です。処理本体はエラー時にプロセスを終了せず、例外を呼び出し元へ伝えます。`UnicodeDecodeError` は `ValueError` の派生クラスで、列数不足や空行も `ValueError` として通知されるため、いずれもこの例で捕捉できます。

同梱の [import.csv](./import.csv) から出力した結果が、基準ファイル [tests/expected_output.xlsx](./tests/expected_output.xlsx) と全シート・全セル一致するかを確認する回帰テストがあります。

```sh
uv run python -m unittest discover -s tests -v
```

計算処理を変更して出力が意図的に変わる場合は、内容を確認したうえで基準ファイルを差し替えてください。基準ファイルは、リポジトリ直下の [.gitignore](../.gitignore) にある `*.xlsx` の例外として、Gitで管理しています。

## コードスタイル

PEP 8に従い、1行の上限は120文字としています([pyproject.toml](./pyproject.toml) の `[tool.autopep8]`)。autopep8は開発用の依存関係(`dev` グループ)で、`uv sync` でインストールされます。

```sh
# 変更内容を確認(ファイルは書き換えない)
uv run autopep8 --diff --recursive .

# すべてのPythonファイルに適用
uv run autopep8 --in-place --recursive .

# 残っている違反を確認(何も表示されなければOK)
uv run pycodestyle --max-line-length=120 --exclude=.venv,__pycache__ .
```

pycodestyleは `pyproject.toml` の設定を読まないため、行の上限と除外するフォルダーをコマンドで指定しています。

## ファイル構成と設定変更

| ファイル | 役割 |
|---|---|
| [main.py](./main.py) | 処理全体の流れ(CSVの読み込み、シートごとの計算と出力、保存)、コマンドライン処理 |
| [sub_functions.py](./sub_functions.py) | 計算の組み立て、Excel出力 |
| [one_pattern_class.py](./one_pattern_class.py) | `OnePattern` クラス。出現値・頻度・期待値の計算、`OnePattern` クラスの生成 |
| [ext_functions.py](./ext_functions.py) | CSV読み込み、条件名とシート名の生成、出現値の文字列化 |
| [init_values.py](./init_values.py) | 入出力の初期値、補正条件、補正の加算値と倍率(倍率は小数点以下1桁まで)、出力列の定義 |
| [import.csv](./import.csv) | 通常入力用の成長期データ |
| [test.csv](./test.csv) | エラー確認用の入力データ(全項目が空欄の1行) |
| [base_spreadsheet.xlsx](./base_spreadsheet.xlsx) | 出力Excelの結果を条件を選んで表示する一覧表のテンプレート |
| [tests/](./tests/) | 回帰テスト(`test_regression.py`)と基準の出力Excel(`expected_output.xlsx`) |

`OnePattern` は一つの経験値パターンに対応したクラスです。`OnePattern` クラスのメソッド `get_ex_values()` は内部リストをそのまま返し、`copy()` メソッドは別のリストを持つ経験値パターンの複製を返します。

依存パッケージを追加する場合は、例えば `uv add openpyxl` を実行します。開発用のツールは `uv add --dev autopep8` のように `--dev` を付けて追加します。設定内のパターン識別子や条件の並び順は計算処理でも使用しているため、変更時は参照側との整合性も確認してください。
